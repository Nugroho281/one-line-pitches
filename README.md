One sentence, 164 characters, that talks a friend who has never coded into letting an AI agent build their first app idea on make.fun — the blind self-judge winner of three original variants (2–0, margins +3 and +2). It speaks as a friend who already knows the idea ("that app idea you keep mentioning over coffee") and promises only what the bounty offers: describe the idea, an AI agent builds a real, working first version today, no coding needed from you.

## Run it

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (UTF-8, one sentence, ≤ 240 characters, deterministic — verified byte-identical across 6 runs).
